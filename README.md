# simplescene
Simple scene selection for A&H Desks - initially SQ.  Uses LOLIN S2 ESP32 platform.  Programmed via Arduino IDE

**Functionality**
- Implements Up and Down buttons and single digit LED display.
- Discovers SQ desk
- Commits select scene via Midi command to discovered desk
- Supports scenes 1-9 though easily extended beyond
- Limited at present to a single desk on the network

**Installation**

- Update credentials for your WiFi network
- Compile & run!  No library installation required
